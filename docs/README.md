# 静的ページ(docs/)

アプリとは別に、HTML・JS・CSS だけで動く静的なページを置く場所です(personal_dashboard-front の docs/ と同じ考え方)。

- 単体で開ける: ブラウザでファイルを開くか、GitHub Pages(公開元を `main` ブランチの `/docs` にする)で見られる
- アプリからも使う: ビルド時に `docs/` の HTML を同梱する(`angular.json` の `assets`)。アプリはこの HTML を読み込んで、自分の画面の中に表示する
- 保存が必要な機能(ランキング・ログインなど)はアプリで開いたときだけ動かし、単体で開いたときは保存なしで遊べるようにする
  - 静的ページとアプリの間で結果を受け渡す仕組みは、最初にクイズを作る Issue で決める

## 構成

```
docs/
  index.html        目次
  assets/docs.css   共通のスタイル
```
